**Funções de Security:** esta base dá o panorama (skill 13) e a operação em infraestrutura (skill 9). A profundidade de código seguro está na *Skill Base Backend/Frontend* (segurança), a de privacidade de dados na *Skill Base Data* (segurança e privacidade) e a de segurança de IA na *Skill Base AI*. Application Security e Privacy Engineering devem combinar essas bases.

> Uma função não *limita* o estudo: serve para priorizar a ordem. Lacunas no núcleo são prioridade; lacunas no apoio são aceitáveis.
