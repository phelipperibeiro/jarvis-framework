# Guia do Nível Container (C4)

> Parte do skill `eng-global-arch-c4`. Leia este arquivo antes da proposta (passo 3) quando o nível pedido for Container (nível 2).

### Container (Nível 2)

**Perguntas a responder:**
1. Quais aplicações compõem o sistema?
2. Quais bancos de dados são usados?
3. Como os containers se comunicam?
4. Há filas ou mensageria?

**Checklist:**
- [ ] Todos os containers identificados
- [ ] Tecnologias documentadas
- [ ] Comunicação clara
- [ ] Bancos e filas mapeados
