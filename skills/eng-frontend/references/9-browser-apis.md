# 9. APIs do Navegador

**Nível:** IMPORTANTE  
**Independência:** ✅ Válido em qualquer framework

## Objetivo
Usar bem o que o navegador oferece nativamente antes de recorrer a bibliotecas.

## Conhecimentos Principais

### Fetch e rede
- Fetch API versus XMLHttpRequest (em conceito)
- Requisições GET, POST, PUT e DELETE
- Cabeçalhos e CORS
- Processamento de JSON
- Tratamento de erros em requisições

### APIs de armazenamento
- localStorage e sessionStorage
- Diferenças e casos de uso
- Serialização (JSON.stringify e JSON.parse)
- Eventos de armazenamento

### Geolocalização e dispositivo
- API de geolocalização (em conceito)
- APIs de vibração e de orientação (em conceito)
- Permissões e privacidade

### Service Workers (em conceito)
- O que são
- Suporte offline
- Estratégias de cache
- Notificações push (em conceito)

### APIs modernas da web
- Intersection Observer (carregamento sob demanda)
- Mutation Observer (mudanças no DOM)
- ResizeObserver (tamanho de elementos)
- requestAnimationFrame versus setTimeout

### APIs de performance
- Performance API
- Navigation Timing
- Resource Timing

## O que NÃO Inclui
- APIs muito especializadas, como gráficos 3D, módulos compilados e acesso a hardware

## Por quê é Universal
As APIs do navegador são padrões da plataforma e valem para qualquer framework.
