# 2. HTML Fundamentals

**Nível:** FUNDAMENTAL  
**Independência:** ✅ Válido em qualquer framework

## Objetivo
Estruturar o conteúdo com HTML semântico, que é a base de tudo no frontend e da acessibilidade.

## Conhecimentos Principais

### Semântica
- header, nav, main, article, section, aside e footer
- Títulos h1 a h6 e sua hierarquia
- Listas (ul, ol, dl), parágrafos, citações e código
- Quando usar um elemento semântico em vez de uma div genérica

### Formulários
- form, input, select, textarea e button
- Tipos de input: text, email, password, number, date, file e outros
- Labels e acessibilidade de formulários
- Validação nativa do HTML
- Envio de formulário e métodos (GET versus POST)

### Mídia e incorporações
- img, picture e source (imagens responsivas)
- video e audio
- iframe: segurança e experiência
- svg: conceitos básicos

### Metadados e estrutura do documento
- Elementos importantes do head
- Meta tags: viewport, charset, description e Open Graph
- link e script: onde posicionar
- DOCTYPE e codificação de caracteres

### Acessibilidade no HTML
- Atributos ARIA (aria-label, aria-labelledby, aria-hidden e outros)
- Atributos de papel (role)
- HTML semântico como a base da acessibilidade

## O que NÃO Inclui
- Sintaxe de motores de template
- Sintaxe de marcação própria de frameworks de interface

## Por quê é Universal
HTML é o padrão do navegador, e seus conceitos valem independentemente de como a página é gerada.
