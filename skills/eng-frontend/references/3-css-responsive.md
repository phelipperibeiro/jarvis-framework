# 3. CSS e Design Responsivo

**Nível:** FUNDAMENTAL  
**Independência:** ✅ Válido em qualquer framework

## Objetivo
Estilizar e organizar o layout para qualquer tamanho de tela, entendendo a cascata e o modelo de caixa.

## Conhecimentos Principais

### Seletores e especificidade
- Seletores de tipo, classe, id e atributo
- Pseudo-classes (:hover, :focus, :active, :nth-child) e pseudo-elementos (::before, ::after)
- Combinadores (descendente, filho, irmão adjacente e geral)
- Como a especificidade é calculada e a cascata

### Modelo de caixa
- Conteúdo, padding, borda e margem
- box-sizing: content-box versus border-box
- Colapso de margens
- Overflow e recorte

### Posicionamento e layout
- position: static, relative, absolute, fixed e sticky
- Contexto de empilhamento e z-index
- Flexbox: container, itens e propriedades principais
- CSS Grid: conceitos de container e itens

### Design responsivo
- Abordagem mobile-first
- Media queries e pontos de quebra (de forma conceitual)
- Meta tag viewport
- Layouts fluidos versus fixos
- Imagens responsivas (picture e srcset)
- Unidades relativas: em, rem, %, vw e vh

### Tipografia, cores e animações
- Pilhas de fontes e fontes web; tamanho, altura de linha e espaçamento
- Modelos de cor (RGB, HSL e HEX) e variáveis CSS (custom properties)
- Contraste de cor (WCAG) e suporte a tema escuro (prefers-color-scheme)
- Transições e animações (keyframes); aceleração por GPU e will-change
- Quando usar CSS em vez de JavaScript para animar

### Espaçamento e alinhamento
- Margin versus padding
- Várias formas de centralizar
- Gaps em Flexbox e Grid
- Alinhamento de itens

## O que NÃO Inclui
- Pré-processadores de CSS
- CSS dentro de JavaScript
- Metodologias específicas de nomenclatura (são prática, não fundamento)

## Por quê é Universal
CSS é o padrão do navegador, e seus conceitos valem para qualquer framework de interface.
