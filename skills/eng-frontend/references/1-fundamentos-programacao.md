# 1. Fundamentos de Programação

**Nível:** FUNDAMENTAL  
**Independência:** ✅ Válido em qualquer framework

## Objetivo
Dominar os conceitos de programação que sustentam o frontend: a linguagem do navegador muda de versão, mas os fundamentos permanecem.

## Conhecimentos Principais

### Essenciais
- Variáveis, tipos de dados e escopo
- Controle de fluxo (condicionais e laços)
- Funções e funções de primeira classe
- Closures e escopo léxico
- Callbacks, promessas e async/await (conceitos, não sintaxe)
- Métodos de array (map, filter, reduce, em conceito)
- Desestruturação e operador de espalhamento (spread), em conceito
- Contexto de execução e o valor de this

### Paradigmas
- Imperativo e declarativo (entender a diferença)
- Funcional: funções puras e imutabilidade
- Orientado a objetos

## O que NÃO Inclui
- Sintaxe específica de decoradores ou de sistemas de tipos adicionais
- APIs específicas de um framework
- Recursos de uma versão específica da linguagem

## Por quê é Universal
JavaScript e TypeScript são a linguagem do navegador, mas os conceitos de programação valem em qualquer contexto.
