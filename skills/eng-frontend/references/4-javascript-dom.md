# 4. JavaScript e DOM

**Nível:** FUNDAMENTAL  
**Independência:** ✅ Válido em qualquer framework

## Objetivo
Manipular a página e reagir ao usuário pelas APIs que o navegador oferece, que são a base de qualquer interface.

## Conhecimentos Principais

### API do DOM
- Selecionar elementos (getElementById, querySelector, querySelectorAll)
- Criar, alterar, adicionar e remover elementos
- Classes e atributos (classList, getAttribute, setAttribute)
- Eventos (addEventListener) e delegação de eventos

### Tratamento de eventos
- Tipos de evento: click, submit, change, input, load e DOMContentLoaded
- Objeto de evento: target, currentTarget, preventDefault e stopPropagation
- Propagação por bubbling e por capturing
- Padrão de delegação de eventos
- Eventos de mouse, teclado e toque

### Document e Window
- Objetos document e window
- history e location
- sessionStorage e localStorage
- Escopo global versus escopo léxico
- Temporizadores (setTimeout e setInterval)

### Navegação no DOM
- Pai, filhos e irmãos (parentElement, children, nextSibling)
- Percorrer a árvore do DOM

### Operações assíncronas
- Callbacks
- Promessas: criação, encadeamento, tratamento de erros e finally
- Combinadores de promessas (all, race e any)
- Async/await como conceito
- Condições de corrida em código assíncrono

### Formulários
- API FormData
- Validação de formulário
- Impedir o envio padrão
- Tratamento de campos de arquivo
- Serialização

## O que NÃO Inclui
- Conceitos próprios de frameworks, como DOM virtual
- Bibliotecas legadas de manipulação do DOM
- Sintaxe de versões específicas da linguagem

## Por quê é Universal
O DOM é a API fundamental do navegador, e todo framework de interface se apoia nele.
