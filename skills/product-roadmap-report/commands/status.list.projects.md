# Status List projects

This is used to create and organize a brief concise list of the projects and your status from status reports files or informations the users provided. 

Please, follow the `rules/status-report-rules.md` to get right guidance and know the main rules of this skill.

The output need to follow the instructions and structure of the template `templates/template-projects-list.md`

**Instructions:**
- If the user already give a path to a folder or informations, or if you are working inside a folder that are Obsidian Vault, look for the files that follow the naming path described in `SKILL.md` or the `references/detailed-guide.md`
- If you can't detect those informations or files, ask to the user to give the files or informations so you can organize and give the right anwser
- Use the most recent files to give the latest status of the projects.
- If user ask to show only projects from an specific team, follow the same template, but show only detected informations about projects and status reports of that team.
