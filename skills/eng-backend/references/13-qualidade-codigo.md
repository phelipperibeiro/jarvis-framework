# 13. Qualidade de Código

**Nível:** FUNDAMENTAL  
**Independência:** ✅ Válido em qualquer linguagem

## Objetivo
Escrever código legível e fácil de mudar, e manter o histórico e a documentação organizados.

## Conhecimentos Principais

### Clean Code
- Nomes significativos
- Funções pequenas e bem definidas
- DRY
- Comentários: quando usar e quando não
- Formatação e estilo consistentes
- Tratamento de erros
- Limites (boundaries) claros

### Refatoração
- Refatorar: o conceito e como fazê-lo com segurança
- Code smells (indicadores de problemas)
- Extract Method e Extract Class
- Substituir números mágicos
- Consolidar código duplicado
- Simplificar condicionais complexas

### Code review
- Objetivos da revisão de código
- Como revisar e como receber feedback
- Automatização com linters e formatadores (em conceito)

### Documentação
- Documentação técnica
- Documentação de API
- Comentários versus código autoexplicativo
- Registro de mudanças (change log)
- Architecture Decision Records (ADRs)

## O que NÃO Inclui
- Linters e formatadores específicos
- Configurações de ferramentas de estilo

## Por quê é Universal
Os padrões de qualidade de código independem da linguagem.
