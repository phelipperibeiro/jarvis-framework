# 9. Testes

**Nível:** FUNDAMENTAL  
**Independência:** ✅ Válido em qualquer linguagem

## Objetivo
Garantir, com testes rápidos e confiáveis, que o código faz o que deve e continua fazendo depois das mudanças.

## Conhecimentos Principais

### Tipos de teste
- Unitários: isolam uma unidade
- Integração: verificam a interação entre componentes
- Ponta a ponta (E2E): percorrem o fluxo completo
- De contrato: validam o contrato das APIs

### Práticas
- Test-Driven Development (TDD): vermelho, verde, refatorar
- Behavior-Driven Development (BDD)
- Cobertura de testes e quando ela é relevante
- Mocks e stubs
- Fixtures e dados de teste
- Padrão Arrange-Act-Assert

### Qualidade dos testes
- Determinísticos (sem testes instáveis)
- Rápidos
- Independentes entre si
- Legíveis
- Pirâmide de testes: muitos unitários, poucos de ponta a ponta

## O que NÃO Inclui
- Frameworks e bibliotecas de teste específicos
- Sintaxe de uma ferramenta de testes

## Por quê é Universal
Testar é uma prática universal, independente da linguagem ou do framework de teste.
