# 1. Fundamentos de Programação

**Nível:** FUNDAMENTAL  
**Independência:** ✅ Válido em qualquer linguagem

## Objetivo
Dominar os blocos construtivos de todo software, que são os mesmos em qualquer linguagem: dados, controle de fluxo, funções, recursão, tratamento de erros e paradigmas.

## Conhecimentos Principais

### Essenciais
- Variáveis, tipos de dados e escopo (global, local, léxico)
- Controle de fluxo: condicionais (if/else, switch) e laços (while, for)
- Funções: definição, parâmetros, retorno e valores padrão
- Recursão: o conceito, o caso base e o estouro de pilha
- Tratamento básico de exceções (try/catch/finally)
- Entrada e saída básicas
- Paradigmas: imperativo, declarativo, orientado a objetos e funcional

### Importantes
- Closures: o que são e como capturam o escopo
- Funções de primeira classe: funções como valores
- Funções de ordem superior (map, filter, reduce, em conceito)
- Callbacks, promessas e async/await como padrão, não como sintaxe
- Sistemas de tipos: tipagem estática versus dinâmica

### Complementares
- Geradores e iteradores (menos comuns)
- Funções puras e imutabilidade

## O que NÃO Inclui
- Sintaxe específica de uma linguagem
- APIs e bibliotecas específicas
- Recursos exclusivos de uma linguagem (por exemplo, modelos próprios de concorrência ou decoradores)

## Por quê é Universal
Todo software é construído sobre esses conceitos. Mudar de linguagem muda a sintaxe, não os fundamentos.
